# CPP00

Basics of C++: classes, member functions, streams and `std::string`.

Part of my C++ modules at [Codam](https://www.codam.nl) (42 Network), written in C++98.

**Concepts:** namespaces, classes, member functions, stdio streams, initialization lists, static members.

## Exercises

| Folder | Exercise | What it does |
| --- | --- | --- |
| `ex00` | Megaphone | Prints its arguments in upper case; a first program using C++ I/O. |
| `ex01` | My Awesome PhoneBook | Small phonebook (`ADD`, `SEARCH`, `EXIT`) built from `Contact` and `PhoneBook` classes. |
| `ex02` | The Job Of Your Dreams | `Account` class re-created from its header and reference log output, including timestamps. |

## Build and run

Each exercise is self-contained. From the repository root:

```sh
cd ex00
make
./<executable>
```

`make fclean` removes the build output. Code is compiled with `-Wall -Wextra -Werror -std=c++98`.
